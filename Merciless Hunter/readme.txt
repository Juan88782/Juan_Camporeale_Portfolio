# 🔥 Merciless Hunter

**Merciless Hunter** is a demo game developed in **Unity** in collaboration with a small team of friends.

Due to shared ownership of the project, I cannot publish the full Unity project nor the C# solution.  
However, I am able to share the complete **player controller code** (fully developed by me)

This repository showcases my contribution to the project, focusing on gameplay programming, mechanics implementation, and character behavior.

---

## 🧠 My Contribution

I was responsible for:

- Player movement system
- Combat mechanics
- Input handling
- State management
- Animation integration
- Gameplay logic and optimization

The shared code reflects my programming structure, problem-solving approach, and clean implementation practices within Unity (C#).
